# OctoAcme Project Management Docs

Welcome! This README provides a summary of OctoAcme's project management approach and links to each of our key process documents.

## Summary of Project Management Processes

OctoAcme uses a lightweight, iterative model that focuses on:
- Clear project ownership and cross-functional roles
- Moving from problem/opportunity through initiation, planning, execution, and delivery
- Risk and dependency management throughout the lifecycle
- Strong communication and regular stakeholder syncs
- Continuous improvement via retrospectives and actionable follow-up

Key artifacts include one-pagers, backlogs, risk registers, and checklists. For details on each stage and supporting templates, see the docs below.
